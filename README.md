# Belajar Vibe Coding

Backend project built with **Bun**, **ElysiaJS**, **Drizzle ORM**, and **MySQL**.

## Getting Started

1. Install dependencies:
   ```bash
   bun install
   ```

2. Setup environment variables:
   ```bash
   cp .env.example .env
   ```

3. Run development server:
   ```bash
   bun run dev
   ```

4. Database Migrations:
   ```bash
   bun run db:generate
   bun run db:push
   ```
